# Payday Tides

A four-story browser puzzle about cash-flow timing, built for [Zoud GameLab 2026](https://itch.io/jam/zoud-gamelab).

[Play the game](https://seb-and.itch.io/payday-tides) · [Concept PDF](docs/payday-tides-concept.pdf) · [Budget PDF](docs/payday-tides-budget.pdf)

Open `index.html` in a browser. `node test-game.mjs` exhaustively checks each story's legal choices and payoff routes. No account, banking data, analytics, or paid runtime is required.
